Bit 88 (byte 11 bit 8), message 1/2: Gender (Boy=0, Girl=1)

Bit 90-91 (byte 12 bit 2-3), message 1/2: Friendship Value (00 for 1, 11 for 4) If opposite gender, hearts are shown instead of smileys.
I'll add more info about mating once my tamagotchi can breed. Baby gender is probably in 3/4 but it'll be hard to figure out if they're boys.

Bit 99 (byte 13 bit 3-4), message 1/2: Costume (00=Nyatchi, 01=Hohotchi, 10 (also 11 but unused)=No costume)

Bit 120 (byte 15 bit 8), message 1/2: Honey activated (0=No, 1=Yes)
In order to do the transmission with the honey with the tamagometer, it needs to produce 00001100 on message 3 or 00001101 on message for the conversation type. 

Also through this, I accidentally found out you can kiss the same gender (and also your own clone). So that's cool. The 00001100/00001101 conversation type does the kiss animation.
