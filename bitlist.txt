Bit 88 (byte 11 bit 8), message 1/2: Gender (Boy=0, Girl=1)

Bit 90-91 (byte 12 bit 2-3), message 1/2: Friendship Value (00 for 1, 11 for 4) If opposite gender, hearts are shown instead of smileys.

Bit 99 (byte 13 bit 3-4), message 1/2: Costume (00=Nyatchi, 01=Hohotchi, 10 (also 11 but unused)=No costume)

Bit 120 (byte 15 bit 8), message 1/2: Honey activated (0=No, 1=Yes)
